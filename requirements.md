Web app for training for Hyrox Pro Doubles Event on March 13th 2027.

Workouts leading up to event will be for 45 mins to 1 hour. Initial workouts may consist of exercises to build VO2 max. E.g. 20 mins of compromised cardio (A hyrox station exercise followed by running), and then a 25 min session of 4x4 method for running/assault bike. 

Towards the end workouts will be geared more towards the actual event.

First session may consist of test that can be used to predict Hyrox Pro Doubles finishing time.

The app is for a single user. To calculate finish time it can be assumed second athlete has same level of fitness and skill.

Web app should be used to log workouts - time taken, weight used, etc and based on each performance the finish time should be recomputed. 

Initial screen shows predicted finish time. Workout screen shows workout for the day options (highly customizable). At end of workout initial prediction is modified based on performance.
